# 图形归属与顶部正文裁切修复（2026-09-22）

本次发布保留公开 MCP 适配层 0.4.0、现有模型与依赖版本，仅更新 BeMarkdown 图形处理。

- 记录遮罩排除图形时的实际归属。非空残余进入待审，不再自动标记通过。
- 自动图题关联排除这些残余；只有残余候选时保留未知关联。
- 顶部正文裁切要求高可信原生文本、独立多行正文归属、没有未归属标签，
  且移除文字后的源绘制区域完全为白色。细线、独立标签或读取失败都会保留原框。

内部固定 6 页回归经过独立核查：33 个图像资产的哈希及引用有效，9 条图题目标不指向残余。
测速仪示例只移除顶部 48 行正文，其余像素完全相同；其他资产哈希不变。
5 个残余节点改为待审，这是状态纠正，不能计作自动修复或审核工作量下降。
这些内部样本及原始日志不随公开仓库分发。

公开源码保留原有发布适配差异，未用内部整个目录覆盖公开版本。
三份回归测试共 20 项通过；公开 wheel 两次构建字节一致，源码与包内文件逐项对应，
所有原有静态资源和第三方许可证均保留。
GitHub Actions 同时检查这些回归用例和官方 MCP SDK 会话。

该验证不代表整个项目达到 90%／95% 准确率或速度目标。新规则也不覆盖所有扫描页、
所有方向的正文侵入或上游已经错误归属的图形标注。MCP 仍要求 agent 复核待审项。

升级现有部署时，拉取仓库更新后按 README 重新执行 setup；已运行的 MCP 会话需要重启，
以载入新 wheel。保留现有知识库与工作区，不必重新导入已整理的教材。
旧客户端配置的首次迁移、依赖复用和失败回退详见[安装与升级说明](INSTALLATION_UPGRADE.md)。
