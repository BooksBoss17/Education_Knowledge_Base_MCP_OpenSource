# 上下文修复与图片处理：开发验证检查点

当前为开发验证阶段，尚未替换正式 MCP，尚未向 GLM 或 DeepSeek 派发新导入。

## 已实现

- 新增 `bemarkdown_review_context`：正常窗口为前3后1，开头依次为后4、前1后3、前2后2；相邻候选触发额外干净段落，文末向前补足。
- 新增语义修复模式：完整目标段唯一匹配、当前 Markdown SHA、上下文哈希、非空白字符数正负1限制。语义推断在日志中用独立 method 标识，原始 Markdown 不改。
- 新增 `bemarkdown_convert_image`：单张正文图片包装为一页 PDF，沿用原模型、运行时和 GPU 队列；记录父任务/图片 SHA、重复请求复用子任务。需显式 review 才能替换父文档内容。
- DOCX 和 PDF 的普通图片在发布资产编号前清除完全单色/完全透明图片；极淡像素、透明通道的有效图形及未识别内容证据保留。
- 教材技能已改为上下文修复优先，装饰图删除、标题直接转写、正文图片调用局部转换；公式、表格、阅读顺序及无法判断的文字仍核对原图。

## 验证证据

- MCP 测试：101 passed（包含段落窗口、相邻候选、短文档、重复内容、陈旧哈希、原文保留、单页图片输入及幂等性）。
- 转换基本回归：26 passed，涵盖新空图测试、生产 DOCX/PDF 包装。
- 资产及 DOCX 图片回归：37 passed，涵盖可见资产契约、混合图片、批次与表格来源图片；与前述套件有重叠，不能相加为独立样例数。
- 实际第一册309个候选中302个成功映射当前正文段落，7个需要来源复核；仅证明可定位，不证明纠错正确率。结果：`tmp/semantic-context-book1-probe.json`。
- 真实教材“致同学们”整页图片，经新增接口生成单页 PDF 后运行当前开发转换器：28.009秒，包校验通过，父文档未改变，1个待复核项。此为含冷启动的单样本，不代表稳定吞吐量，也不是内容准确率认证。来源图片已实际查看，输出仍需恢复排版/栏目间距并处理保留图。证据：`tmp/semantic-image-review-20260913/result.json` 及同目录 `request.json`、`output/`。
