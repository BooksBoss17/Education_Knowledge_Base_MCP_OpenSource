# BeMarkdown-Retention-B200

独立的教材图片留存分类模型，基于 Qwen/Qwen3.5-4B 的 B200 LoRA 检查点。当前冻结配置为 Q4_K_M 语言权重、配套 F16 视觉投影器、原提示词与门控0.8；全部用途按 K>U>D 聚合，待核 U 保留。极端长宽比>200时仅补白到短边至少32，无缩放或裁切，不凭比例删图。

## 状态与验证范围

已存放在 MCP MODELS 中，**未接入 BeMarkdown 自动线路**。完整同金标开发集1535项：正确率96.7427%（U计错）、实际留存精确率94.9657%、必要召回99.8797%，待核33项、误删1项。用户接受该版本并冻结，但原97%/零误删数值门槛未通过。不声称独立新教材泛化，也没有新12本终验。

隔离分类worker508.922秒；采样工作集3.298GiB、私有提交4.976GiB、整卡显存4663MiB。这不是完整PDF/OCR流程的资源认证。模型适合辅助筛查；证据不足须保留待核。

## 文件与许可

`B200-Q4_K_M.gguf` 与 `mmproj-F16.gguf` 必须配对使用。`adapter/` 保存原LoRA权重及可移植基座身份，非完整HF基座；基座 revision 为 `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`。GGUF架构为 qwen35，需支持该架构及对应视觉投影的 llama.cpp；转换器 commit `7fe450e19305b828c199d602c23a8337aaa1f03b`。单独对话输出K/D不能替代完整用途汇总和置信门控。

模型、LoRA和本仓库独立工具采用 **Apache-2.0**，保留 Qwen 来源及修改说明。BeMarkdown/MCP 程序本身仍按其 AGPL-3.0 及第三方例外许可分发。训练教材、评测图片、原文、缓存和优化器状态不包含在发布中。训练数据总计4270个资产、4258实际准入；开发1535项，金标未改。
