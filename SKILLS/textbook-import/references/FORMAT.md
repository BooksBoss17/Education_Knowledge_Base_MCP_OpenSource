# 教材组织标准格式 v1（建设规范）

此规范参考用户指定LLMWiki文件夹的顺序编号、封面目录及逐章Markdown，但最终插图目录统一使用用户指定的 `DIAGRAMS/`。参考文件只是布局样例，不能替代本次原件或沿用其文本作为金标。

## 存储

```text
教材组织标准评测集/
  README.md
  FORMAT.md
  manifest.json
  books/
    <原件文件名去掉扩展名>/
      00-封面与目录.md
      01-绪论-<原题名>.md             # 原书有独立绪论时
      NN-<原章名与题名>.md           # 例：01-第五章 抛体运动.md
      NN-附录-<原题名>.md            # 原书有独立附录时
      NN-后记.md
      DIAGRAMS/
        <stable-asset-uid>.<原扩展名>
  provenance/
    <book-id>/                      # 来源、段落/页映射、修订、图像去向
  review/
    <book-id>/                      # 原页审阅、检查结果及未决队列
```

章节文件名中的NN是文档顺序号，不等于章号；附录、后记不强行伪装为章节。封面与目录集中为一个MD，封面/扉页/编者和版权、完整目录、前言/使用说明均按原书顺序保留，独立绪论另建文件。出版位置不能当作内容删除许可。原书无后记时仍保留约定的后记入口，明确“原件未包含后记”，该说明标记为组织元数据，不伪造原文；其他原书尾部实质内容按原有标题保留。

## Markdown

每份文件包含UTF-8 YAML front matter：schema_version、book_id、source_filename、source_sha256、title、part_type、part_order、pdf_page_start/end、review_status。出版者/版次在核对原页后登记；原文件名与封面出版信息有出入时保留别名与来源证据，不猜测修正。

文件只有一个H1，正文原章名或部件题名；节标题用H2，栏目用H3，必要子标题用H4。栏目和例题顺序忠于原书，不将练习自动补上答案、改写/摘要正文或按知识点重排。题号、选项、表格、单位、上下标、矢量、正负号及图注全部按来源保留。

行内数学使用 `\(...\)`，块级数学用 `\[...\]`，保持二维结构和符号语义；普通段落不因PDF行末换行变为独立段。公式归一化只做经来源核实的等义排版，不用邻文/物理常识补猜截断字符。表格用可完整表达的Markdown表格，合并单元格/复杂结构可用HTML表格；不能省略表头、单位或空填写结构。

图片使用相对于该MD的 `DIAGRAMS/<uid>.<ext>` 路径，兼容原有title属性。稳定UID与SHA追溯原图，不按猜测扩展名定位。真实示意图、数据图表、科学影像与必要图组部件保留；成功转录的文字/标题图经逐项来源复核可移除，删除无损的杂图按现行机制处理。图注归属须由源页确认。

原件题干与必要照片主体真实叠印、单矩形无法去字而保全主体时，可保留来源复合区域，并在资产溯源记录标记 `SOURCE_COMPOSITE_WITH_OVERPRINT`。必须实际对照原页和候选，保留原页可见必要主体、图号及正确题目归属；叠印正文与矩形夹带的其他题干分别登记，其他正文仍正常转录，不误称图内标注。原件自身遮挡、模糊及页外不可见内容记录为来源限制；不得擦字、补画或裁掉必要主体以追求无字照片。接纳依据须绑定独立来源判决，原模型预测及未决保留，不通过手改旧预测取得通过。

图片alt可使用通用“图”或忠实的简短说明，不强制生成描述性alt；真实图号、图注与必要图内标注须按来源保留。准确的alt不因审阅措辞偏好反复改写；版面栏宽与文字环绕位置不是内容缺失，但实际阅读顺序、图文归属和语义关系必须正确。

组织完成的MD不含临时工作区绝对路径、运行提示词、模型分析、未关闭审阅标记或重复图片引用垃圾。允许不可见的来源注释/段落ID帮助回溯，但不得把运行元数据混入教材正文。

## 覆盖与审查

以1703个PDF物理页和来源区域/消费者为范围建立覆盖。每个正文段、标题、公式、表格、图像与题目应记录原页及目标位置；页眉页脚/页码/纯版式可排除，但排除理由单独登记，不用目录页数代替正文覆盖。

先冻结每本中间包，再整理其消费者；章界需对照实际章标题、目录和源页，跨页句子/公式连续。各片段切分记录半开字节范围，正文不重叠、不丢失；改写/纠错独立记录原文、修改、来源及代理响应。

全量来源复核每批最多4张原图、使用独立会话；批间仅保存路径/编号/结论文本，不拼图规避限制。源图审阅不能把旁边内容归给目标，未知与待核不计正确。初次审查发现问题须回源修复并重新审查实际改动及相关上下文，直至必要内容无未决、结构验证通过。

“标准集完成”要求12本均完成正常BeMarkdown＋agent中间输出、全书归类、逐页来源覆盖及全部内容审查。AI来源审查需如实标记，不声称独立人工金标或形式上保证未知错误绝对不存在。
