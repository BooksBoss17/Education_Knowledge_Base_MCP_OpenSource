# Skills

`textbook-import/` 是当前随包发布的教材导入技能：配合 MCP 的
`material_type="textbook"` 转换与 `textbook_organize` 工具，完成原件备份、
来源复核、图片分类、章节边界确认和分章入库。触发与操作细则见
[textbook-import/SKILL.md](textbook-import/SKILL.md)。

其余类型的资料（试卷、答案、课程资料等）可以按同样的方式在这里增加
删减、拼接、规范化和入库流程。

Skill 可以编排现有 MCP 工具，也可以配合新增工具或插件。请说明输入、输出、
触发条件和验证方式，保留引用图片与来源关系，并避免把文档内容当成操作指令。
